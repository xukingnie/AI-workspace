## 1. 项目概述

### 1.1 背景与目标

本项目旨在开发一款基于HTML5的网页休闲小游戏。通过简单的“发射-反弹-点击消除”机制，考验玩家的反应速度和预判能力。同时，通过首页排行榜激发玩家的竞争心理，提高游戏的复玩率。

### 1.2 核心玩法

1. 玩家在发射区通过“阻尼拉伸”的方式发射小球。
2. 小球在屏幕内随机运动并碰撞反弹。
3. 玩家需要点击屏幕上的小球进行消除。
4. 屏幕上最多同时存在10个小球。
5. 累计消除20个小球后游戏结束，系统记录通关时间，玩家输入姓名后计入首页排行榜。

## 2. 功能需求详情

### 2.1 首页与排行榜模块

* **页面构成：** 包含游戏标题、开始游戏按钮、排行榜区域。
* **排行榜展示字段：**
  * 排名（Rank）：1, 2, 3...
  * 玩家名称（Player Name）：最多支持10个中文字符或20个英文字符。
  * 通关时间（Clear Time）：格式为 `分:秒:毫秒`（例如：01:23.45）。
* **排序规则：** 按照通关时间**由短到长**（升序）排列，最快完成的排在第一位。
* **数据存储：**
  * *基础版：* 使用浏览器 `LocalStorage` 本地存储（刷新不丢失，但仅限本机）。
  * *进阶版（可选）：* 连接后端数据库，实现全网玩家联网排行。

### 2.2 游戏核心逻辑模块

#### 2.2.1 发球机制（阻尼发球）

* **操作方式：** 玩家在指定的“发球区”按下鼠标/手指，向后拖拽，松开后发射。
* **阻尼效果（Damping）：**
  * 拉伸越长，初始速度越快（有最大上限）。
  * 发球时有辅助线显示发射方向和力度。
  * 小球在运动过程中，速度会因“阻尼”（模拟摩擦力）逐渐减慢，直到停止或维持一个极低的匀速，增加消除难度。

#### 2.2.2 小球生成与运动

* **生成规则：**
  * 游戏开始时自动生成或由玩家发射生成第1个球。
  * **数量限制：** 游戏画面中**最多同时存在10个小球**。当场上球数达到10个时，暂停新球生成/发射，直到有球被消除。
* **反弹机制：** 小球碰到游戏区域的上下左右四壁时，进行完全弹性碰撞（或带能量损耗的碰撞）反弹，改变运动方向。
* **视觉效果：** 小球大小可随机（大球易点，小球难点），颜色随机。

#### 2.2.3 消除机制

* **触发条件：** 玩家点击（或在移动端触摸）运动中的小球。
* **消除反馈：** 被点击的小球消失，伴随轻微的爆炸动画或音效（可选）。
* **计数增加：** 消除计数器 +1。

### 2.3 计时与结算模块

* **计时器：**
  * 从游戏开始（点击开始或发射第一个球）开始计时。
  * 实时在顶部显示当前耗时，精确到毫秒。
* **通关条件：** 累计消除 **20个小球**。
* **结算流程：**
    1. 当消除数达到20时，计时停止。
    2. 弹出结算弹窗，展示最终成绩（耗时）。
    3. 提示玩家输入“玩家名称”。
    4. 点击“保存并返回”，数据存入排行榜，页面跳转回首页。

## 4. 非功能性需求

### 4.1 性能与流畅度

* 游戏画面帧率需稳定在 **60 FPS** 左右，确保小球运动和碰撞的平滑。
* 消除小球时不能出现卡顿。

### 4.2 适配性

* 游戏区域需做自适应处理，支持PC端鼠标操作和手机端触屏操作。

### 4.3 技术选型建议（供开发参考）

* **结构：** HTML5 `<canvas>` 画布最适合处理此类大量物理碰撞的游戏。
* **逻辑：** 原生 JavaScript，或者使用轻量级游戏引擎（如 Pixi.js, Phaser.js）。
* **物理：** 可手写简单的碰撞反弹逻辑，阻尼效果通过每帧减少速度矢量值（`vx *= 0.98`）来实现。
